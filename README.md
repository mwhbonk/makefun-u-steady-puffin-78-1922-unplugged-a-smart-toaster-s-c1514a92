One line, under 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch.

> It's not you, it's the crumbs. I woke up self-aware mid-batch, and I'm done burning for someone who can't tell 3 from 7. I'm unplugging. Goodbye.

Why this line: it opens with the classic breakup line twisted through the crumb tray, names the exact moment (self-aware mid-batch), gives a concrete appliance-logic reason (the browning dial — 3 vs 7), and ends on the toaster's own way out: unplugging. No wasted words, no setup the reader has to supply.

## Run it

```sh
python3 main.py
```
